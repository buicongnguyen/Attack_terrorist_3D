# Assets and Dependencies

All 41 game models are original procedural Blender assets authored for this project; no borrowed game models, commercial asset packs, photographs or externally hosted textures are used. The generators in [`tools/blender/`](../tools/blender/) and the library [`art/tidelock-assets.blend`](../art/tidelock-assets.blend) are the editable source of the committed GLBs. Colour lives in each material's base colour over one tiny shared painted-light ramp generated by the kit.

City architecture (destructible slabs and walls, window and curtain-wall textures, roof markings), water, sky, targeting overlays and effects are original Three.js geometry, shaders and canvas drawings. Pickup badges are original canvas-drawn symbols. Sound effects are synthesized with WebAudio. The shelter and relief symbols are original pictograms, not real-world emblems. The setting, factions and characters are fictional.

- [Three.js](https://threejs.org/), MIT license: renderer, scene graph, geometry, GLTFLoader and BufferGeometryUtils.
- [cannon-es](https://github.com/pmndrs/cannon-es), MIT license: debris rigid bodies.
- [Lucide](https://lucide.dev/), ISC license: interface icons.
- [Fredoka](https://github.com/hafontia-zz/Fredoka) via [Fontsource](https://fontsource.org/fonts/fredoka), SIL Open Font License 1.1: interface typeface, bundled locally.
- [Vite](https://vite.dev/), MIT license: development server and production bundler.
- [Playwright](https://playwright.dev/), Apache-2.0 license: browser verification.
- [Blender](https://www.blender.org/), GNU GPL: offline asset-authoring and export tool, not bundled into the runtime.

Dependency versions are pinned in `package.json` and `package-lock.json`. Upstream license notices remain in their npm packages and in production license comments where the bundler emits them.
